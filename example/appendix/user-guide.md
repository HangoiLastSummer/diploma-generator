# Введение

Руководство описывает установку и использование приложения LabTrack. Оно предназначено для администратора кафедры и преподавателей.

# Руководство по установке разработанного программного обеспечения

## Назначение программы

Приложение ведёт журнал сдачи лабораторных работ и формирует отчёты.

## Системные требования

Для работы требуется сервер с 4 ГБ оперативной памяти и 20 ГБ свободного места на диске.

## Необходимый минимальный набор программного обеспечения, требуемый для работы разработанного ПО

Необходимы Docker и PostgreSQL версии не ниже 15.

## Описание процедуры установки разработанного ПО

Запуск выполняется командой, приведённой в листинге @lst:run.

```bash {#lst:run caption="Запуск приложения"}
docker compose up -d
```

После запуска приложение доступно в браузере по адресу сервера.
