# Исследование и анализ предметной области

## Описание поставленной задачи, ее обоснование

Разрабатываемое приложение должно заменить бумажные ведомости электронным журналом. Архитектура системы показана на рисунке @fig:arch, основные сущности перечислены в таблице @tbl:entities. Серверная часть реализуется на ASP.NET Core [@aspnet], данные хранятся в системе управления базами данных (СУБД) PostgreSQL.

![Архитектура приложения LabTrack](img/arch.png){#fig:arch width=80%}

Клиент обращается к серверу через программный интерфейс приложения (API), сервер хранит состояние в базе данных. Такое разделение позволяет менять интерфейс, не затрагивая бизнес-логику.

Таблица: Основные сущности системы {#tbl:entities}

| Сущность | Назначение | Поля | < |
| ^ | ^ | ключевые | прочие |
|---|---|---|---|
| Student | Студент | фамилия, группа | e-mail |
| Lab | Лабораторная работа | номер, дисциплина | срок |
| Submission | Факт сдачи | дата, оценка | комментарий |
| Report | | | |

Регистрация сдачи выполняется методом, приведённым в листинге @lst:submit. Метод проверяет срок и сохраняет запись в журнале.

```csharp {#lst:submit caption="Регистрация сдачи работы"}
public async Task<Guid> SubmitAsync(Guid student, Guid labId,
    CancellationToken ct)
{
    var lab = await _labs.GetAsync(labId, ct);
    var submission = Submission.Create(student, lab, _clock.Now);
    await _submissions.AddAsync(submission, ct);
    return submission.Id;
}
```

Итоговая оценка за дисциплину вычисляется по формуле @eq:grade.

$$ G = \frac{1}{n} \sum_{i=1}^{n} g_i $$ {#eq:grade}

где $g_i$ – оценка за i-ю лабораторную работу, баллы;
$n$ – число лабораторных работ.

Требования к системе включают:
- Ведение журнала сдачи;
- формирование отчётов по группам
- разграничение прав студента и преподавателя.

Рабочее место пользователя должно соответствовать требованиям санитарных норм [@sanpin].
