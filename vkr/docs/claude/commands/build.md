description: Собрать docx и разобрать предупреждения вёрстки
---
1. `vkr fix`, `vkr check --format json` — если есть ошибки, исправь и повтори.
2. `vkr build -o vkr.docx`.
3. Разбери `report.json`. Предупреждения, которые лечатся без смены смысла, исправь сам. Остальные (рисунок в начале страницы, нехватка объёма, длинная аннотация) — покажи мне со страницей, строкой исходника и конкретным вариантом правки. При необходимости посмотри страницы через `vkr preview --pages N-M`.
4. Итог одной строкой: страниц всего / без приложений, ошибок, предупреждений.
